Mirror This Site

LibreAI is a static site. One command gets everything. No server, no database, no dependencies.

Full mirror with wget

Downloads the entire site as static files. Serve it from any web server.

wget -r -k -p -np https://libreai.org

Clone from GitHub

The canonical source. Always up to date. Run git pull to sync.

git clone https://github.com/Bardia323/LibreAI

Serve locally

Any static file server works. The data lives in data/models.json.

python -m http.server 8080
npx serve .

Just the index

Want only the model data? Fetch or mirror a single JSON file.

curl https://libreai.org/data/models.json

Keep it alive

The more mirrors exist, the harder this becomes to kill. Deploy on any static host: GitHub Pages, Cloudflare Pages, Netlify, IPFS, your own VPS. If the main domain goes down, the index lives on in every clone.

Add your mirror

Running a mirror? Open a PR to add it to the repository.
