Submit

Add a model — or a magnet for one already listed — to the index.

  1. Fill the form below. Choose New Model for something not yet indexed, or Add Magnet to Existing to attach a download to a listed model.
  2. Click Generate Submission — it builds the JSON and a Open GitHub Issue button (pre-filled and labelled). Submit that issue. All you need is a free GitHub account.
  3. A bot checks it and routes it automatically — you'll get a comment with the result.
Auto-merge The magnet resolves to only .safetensors / .gguf / text files, and nothing duplicates an existing entry.
Review The magnet can't be verified (no seeders yet) or contains other file types — a maintainer reviews the PR.
Rejected The HuggingFace URL or the magnet's infohash already exists in the index.
